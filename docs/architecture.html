Hermaguard — Review Pipeline

One review run: code → deterministic pre-passes → three adversarial agents → trust gates → verified report → learning loop

Accountability

  • • 32 bug classes tracked per report
  • • every class: finding, clean, or N-A-with-reason
  • • gaps fail the coverage check — no silent skips

Evidence

  • • PoCs run in a hardened sandbox (rlimits, empty env)
  • • verdicts from execution output, not model claims
  • • races / async bugs require VERIFIED proof

Learning

  • • dismiss a false positive 3× → suppression rule
  • • prescan applies rules on every future run
  • • suppression visible in stats, never silent
